🌐 Personal Portfolio Website

This is a responsive personal portfolio website developed to showcase my skills, projects, and academic background as a Software Engineering undergraduate.

The website provides a clean and interactive interface to highlight my work, technical expertise, and publications.

🚀 Features
  Responsive design for all devices
  Modern and clean UI
  Project showcase with live demo and GitHub links
  Publications section with detailed articles
  Smooth navigation between sections
  Contact section with social links

🛠️ Technologies Used
      HTML5
      CSS3
      JavaScript
      Font Awesome

📂 Project Structure
      index.html – Main structure of the website
      styles/ – All CSS files (header, about, education, etc.)
      assets/ – Images and media
      script.js – JavaScript functionality
